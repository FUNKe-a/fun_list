# fun_list

A locally hosted list for movies and series.

## Build requirements

* Go 1.26
* sqlc
* sql-migrate

## .env file
set the following env variables.

| NAME                 | VAL                         |
|----------------------|-----------------------------|
| JWT_PRIVATE_KEY_PATH | PEM encoded private rsa key |
| JWT_PUBLIC_KEY_PATH  | PEM encoded public rsa key  |
|                      |                             |
